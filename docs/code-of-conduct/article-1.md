# 1. Preamble {#preamble}

* 1.1. ESN Cyprus endorses the Code of Conduct established by ESN International. In adherence to this code, ESN Cyprus
  has fully embraced and adopted articles 2, 3, and 4.

* 1.2 This document was developed around the idea that everything we do in connection with ESN will and should be based
  upon mutual respect and understanding. It set out to ensure that every person feels safe, included and respected
  during their involvement with ESN.

* 1.3 The behavioural standards of the Code of Conduct are:
    * Respect for inherent dignity;
    * Non-discrimination;
    * Full and effective participation and inclusion in ESN;
    * Respect for difference and acceptance as part of human diversity and humanity;
    * Equality and equal treatment.
